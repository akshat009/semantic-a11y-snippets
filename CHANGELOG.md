# Changelog

## 1.0.0

First release: 63 snippets.

- 53 HTML snippets for HTML and PHP files: semantic page boilerplate (`a11y-page`, alias `html5s`), landmarks, content, media, forms and ARIA widgets.
- 7 CSS snippets for CSS, SCSS and Less: visually hidden class, skip link, focus ring, reduced motion, forced colors, target size and a combined base block.
- 3 JavaScript snippets that wire up disclosures, tabs and toggle buttons.
